# Troubleshooting an etch rate step on both etch tools

Copyright (c) 2026 Bryan C. Weis and Common Consulting Company

When etch rate steps on both E-01 and E-02 after a shared gas delivery, start with the material lot and the supplier notice. A document-only liner note on one tool does not explain the same step on the other tool.

Check lot identity, material code, and which tools consumed the lot. Then read any engineering change and confirm its tool list. A change that names only E-01 cannot be the common cause of an E-02 step.

If the step is confined to one chamber and grows slowly for weeks, review RF hours since the last clean instead of a new lot.
