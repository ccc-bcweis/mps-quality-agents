# Service bulletin for edge ring revision C

Copyright (c) 2026 Bryan C. Weis and Common Consulting Company

Edge ring revision C changes the ESC thermal boundary on MPS-E7. Edge ring revision C was introduced for tool E-02 chamber A. The oxide etch main step still targets ESC temperature 48-56 C.

Edge ring revision C is a hardware change. Compare the engineering change effective time with the oscillation onset. A preventive maintenance work order in the same week is not the change that moved the thermal boundary. Edge ring revision C does not apply to E-01 unless that tool's config names the same part revision.

Verify the PLM config part name is the edge ring and the revision letter is C before recommending a corrective action.
